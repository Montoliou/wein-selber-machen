# Audit-Regeln

1. Keine erfundenen Messwerte.
2. Kritische Dosierungen nie aus freiem Text ableiten.
3. Gärende nie nur über „kein Blubbern“ bestimmen.
4. pH und freier SO₂ für Langzeitausbau/Abfüllung berücksichtigen.
5. Kopfraum ist Pflichtvariable.
6. Süßer Wein darf ohne Refermentationsschutz nicht abgefüllt werden.
7. Sorbat ist kein echter Gärstopp.
8. Presswein immer getrennt führen.
9. H₂S / faule Eier = ORANGE.
10. Fruchtfliegen / Oberflächenfilm = RED.
11. Keine Langzeitlagerung unter Gärspund ohne regelmäßige Kontrolle.
12. Jede Langzeitphase bekommt Reminder.
13. Jede Zugabe mit Stoff, Produkt, Menge, Charge, Zeitpunkt.
14. Messungen nur verpflichtend, wenn sie eine Entscheidung verändern.
15. Unsicherheit sichtbar anzeigen.
